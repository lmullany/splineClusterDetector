# State Location Dataset

A data set that provides latitude and longitude for each state in the
United Sates

## Usage

``` r
states
```

## Format

A data frame with 56 rows and 5 columns:

- state_name, state:

  full and abbreviated names for states

- state_fips:

  state fips codes

- longitude, latitude:

  numeric coordinates for state fips
